# Product definition (locked 2026-06-11, user's words)

1. Keep-style simple list of tasks — easy to see, add to, and edit, with
   minimal noise and ease of workflow.
2. The system keeps track of general goals so the user never has to
   manually think about them while doing the Keep-style plan.
3. The right amount on the day — never under- or overworked (capacity by
   effort estimates, not clock scheduling).
4. Balance and fun planned naturally (nourishment is a first-class input,
   not an afterthought).
5. The basis of the user's GENERAL organisation and planning system:
   folders hold planning documents (protocols, plans — e.g. eczema
   planning) because those decompose into tasks. Philosophy writing does
   NOT live here (that is the Mind corpus / map system).

Governing principle: agency inversion — the user authors the day, the
system advises. Nothing enters the list uninvited except due recurring
tasks (marked, one-click eject).

Hard constraints from the idea-review (2026-06-11):
- Suggestion learning may dampen but NEVER suppress a task to zero; every
  active task has a minimum tray resurfacing frequency.
- Quiet hours can be broken only by rare due-soon AND important tasks.
- Temptation bundling pairs only passive-attention nourishment
  (old favourite album, audiobook) with grind tasks — never full-focus
  material.
- Time tracking via an explicit start/pause/stop timer feeds forecasting;
  no pillar minute-quotas.
- Rejected: two-minute capture lane, share-target, Hemingway-bridge
  prompt, pillar minute-targets, interstitial journaling.
