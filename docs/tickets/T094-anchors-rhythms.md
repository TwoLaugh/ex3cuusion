# T094 — Anchors & rhythms

- Habit stacking (12): tasks can anchor to habit chips ("after Brush PM");
  renders as a chain on the strip; anchor moments are the no-clock answer
  to time intentions.
- Quiet hours (13): after a set evening hour the tray offers only
  wind-down/nourishment. CARVE-OUT: a task may break through only if due
  within ~48h AND high importance (rare by construction).
- Frog of the day (14): mark one list item as the frog each morning;
  streak for frogs done.
- Fresh-start triggers (18): Mondays/month-starts surface ONE stalled
  meaningful task as a restart suggestion.
