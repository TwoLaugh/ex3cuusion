# T013: Polish Mobile Web

## Goal

Make the web-first V1 usable on phones before deciding Android implementation.

## Scope

- responsive Today layout
- full-height burger drawer
- bottom-right inbox safe-area placement
- project drawer as bottom sheet
- thumb-accessible complete/defer actions

## Requirements

- Today remains the default page.
- No native Android or launcher work in this ticket.
- Text and controls must not overlap on narrow screens.

## Acceptance

- Today, inbox overlay, project drawer, and deferral modal work at common mobile widths.
- User can complete, defer, capture, and review from mobile web.
