# T046: Project Panel Task Rollups

Status: implemented in V1 foundation.

## Goal

Make Projects useful as a planning surface for containers/categories, not just a static list.

## Scope

- Show active task counts per project/container.
- Show the next few tasks inside each project.
- Surface project kind, planning mode, and default block size.

## Acceptance Criteria

- Project cards expose enough task context to understand what is inside.
- Relationship/suggestion containers remain visibly distinct from project blocks.
- The panel works without introducing manual CRUD yet.
