# T047: Day Navigator As Week UX

Status: implemented in V1 foundation.

## Goal

Treat the existing day-by-day navigator as the week inspection mechanism, with burger panels carrying backlog visibility.

## Scope

- Preserve the current forward/back day flow.
- Add Planning Preferences summary counts for week/backlog and scheduling model state.
- Avoid a dense seven-column calendar until real usage proves it is necessary.

## Acceptance Criteria

- The app explains wider task state through panels, not a separate week calendar.
- Current date dots and previous/next day controls remain primary.
- Planning preferences summarizes this-week, next-week, someday, blocked/waiting, and scheduling semantics.
