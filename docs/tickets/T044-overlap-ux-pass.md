# T044: Overlap UX Pass

Status: implemented in V1 foundation.

## Goal

Make overlapped work feel intentional in the day timeline instead of looking like a layout bug.

## Scope

- Show compact mode/load badges on plan items.
- Offset overlapping timeline blocks into lanes.
- Expose scheduling semantics in the Tasks and Planning preferences panels.
- Add E2E coverage for the visible UX.

## Acceptance Criteria

- Concurrent/background tasks show visible badges.
- Overlapped blocks remain readable on desktop and mobile.
- Planning preferences summarizes active scheduling semantics.
